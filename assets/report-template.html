全店共性短板根因分析
为什么全员需求挖掘 0 分、信心建立 0 分？
直接原因
  • 5 段录音脚本均为"确认姓氏 + 确认城市 + 承诺开业通知"的轻量确认脚本
  • 脚本设计本身未包含需求挖掘 4 字段（购车阶段/预算/车型/功能）
  • 脚本设计本身未包含信心建立 3 字段（实车/核心体验/盲订权益）
深层原因
  • 盲订期目标定位为"信息确认 + 开业通知承诺"，非销售转化导向
  • 座席培训尚未覆盖"客户主动发问 = 深度挖掘机会"的识别与承接
  • 话术库缺少"异议承接后反问 + 拉回本品"的标准化模板
影响评估
  • 需求挖掘 0 分 → 客户分层运营缺少输入，后续跟进周期无法差异化
  • 信心建立 0 分 → 盲订期品类教育窗口错失，品牌差异化定位未传递
  • 邀约成功 33 分 → 加微率 0%，盲订期最核心 KPI 未达成
改进建议
需求挖掘（全店 0 分，权重 0.20）
核心动作：结束前追加"四问闭环"
① 您目前是首台车还是置换？

③ 纯电和增程哪个更适合您？
④ 您更关注智能功能还是空间续航？
信心建立（全店 0 分，权重 0.15）
核心动作：客户问"车何时出来"时同步植入核心卖点
"爱瓦汽车是以 AI 生态和智能座舱为核心的新能源车品牌，盲订期有专属权益（具体内容待定），门店开业后您可以现场体验实车。"
邀约成功（全店 33 分，权重 0.20）
核心动作：固定收尾加微话术
"我这边先加下您的微信，等门店开业和盲定权益发布，第一时间同步给您，方便吗？"
异议处理（刘华 30 分，权重 0.15）
核心动作：承接后追加反问 + 拉回本品
"我们正在紧锣密鼓筹备中，您大概什么时候打算提车？如果比较着急，我可以优先把 AI 生态体验和盲定权益（具体内容待定）同步给您。"

当前话术已达标，可选择性补齐门店归属 + 意向车型埋点，进一步提升亲和力
